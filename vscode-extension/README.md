# Browser Bridge

Connect your AI IDE to Chrome browser for real-time debugging, DOM inspection, and remote browser control.

## Features

- 📊 **Live DOM Streaming** - See page content in your IDE
- 🚨 **Error Capture** - Console errors streamed to IDE
- 🌐 **Network Monitoring** - Failed API calls detected
- 🖱️ **Remote Control** - Click & type via MCP tools
- 🔍 **CORS Diagnostics** - Detect and diagnose CORS issues

## Commands

| Command | Description |
|---------|-------------|
| `Browser Bridge: Setup` | Run setup wizard |
| `Browser Bridge: Start Server` | Start WebSocket server |
| `Browser Bridge: Stop Server` | Stop server |
| `Browser Bridge: Check Status` | Check connection status |

## Requirements

- Python 3.8+
- Google Chrome with Browser Bridge extension
